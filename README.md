# 🦆 Stremio Tools

A collection of utilities designed to simplify the setup and configuration of Stremio accounts and services.

### [🚀 Launch Tools](https://duckkota.gitlab.io/stremio-tools)

## 🛠️ Included Tools

- **QuickStart**: A streamlined wizard to set up a new Stremio account in seconds.
- **Time Machine**: Backup and restore your Stremio addons and configuration snapshots.
- **Cloner**: Easily clone one Stremio account to another.

## 💻 Running Locally

You can run the tools locally using the included script. Since these are static tools, no heavy installation is required.

### Prerequisites
- Python 3 (standard on macOS)

### Start
Run the included startup script to launch the local server:

```zsh
./start.zsh
```

This will:
1. Start a local Python HTTP server on port 3000.
2. Automatically open the tools dashboard in your default browser.

To stop the server, simply press `Ctrl + C`.
